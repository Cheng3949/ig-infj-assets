# 簡譜排版器 — 一句一行

專門排「一句歌詞 = 一行」嘅簡譜（lead sheet），同一般填滿式嘅譜唔同。

**點用**：直接用瀏覽器開 `leadsheet/index.html`（唔使裝嘢、唔使開 server），
左邊打字、右邊即時見到排版，撳「列印 / 存 PDF」就印得。

## 三個設計重點

| | 做法 |
|---|---|
| **一句一行** | 每句歌詞永遠唔會被斷開。斷行位由你喺原稿入面決定，唔係由紙嘅闊度決定。 |
| **每行下面留白** | 每句下面固定留一段白，用嚟手寫筆記，或者打一行英文歌詞（`>` 開頭嗰行）。高度可調。 |
| **闊度跟歌詞** | 每粒音符嘅欄闊 = 個字有幾闊（中文字通常闊過數字），唔係跟音符。 |

句子太長塞唔落一行嘅時候，會**自動**：先收窄音符之間嘅間距 → 仲唔夠就橫向壓窄字體 →
再唔夠就連字級一齊縮細。總之一定塞返晒喺同一行。

## 原稿格式

```
標題：小星星
調：1=C
拍：4/4
曲：法國民謠

[A]
1 1 5 5 | 6 6 5 -
一閃一閃亮晶晶
> Twinkle, twinkle, little star,

4 4 3 3 | 2 2 1 - ||
滿天都是小星星
> How I wonder what you are.
```

一句 = 一組行，**用空行分隔**：

1. **第一行**：音符
2. **第二行**：歌詞（想要第二段歌詞就再寫多一行，會疊喺下面）
3. **`>` 開頭**：印喺留白入面嘅字（英文歌詞、和弦、提示……可以有幾行）

### 標題資料（放喺最頂）

`標題` `副標題` `調` `拍` `速度` `詞` `曲` `編曲` `唱` `備註`
（英文 `title` `key` `time` `tempo` `lyricist` `composer` 等都得）

### 段落標記

用中括號自己一行：`[A]`　`[主歌]`　`[副歌]`　`[Bridge]`

### 音符寫法

| 寫法 | 意思 |
|---|---|
| `1`–`7` | 音；`0` = 休止符 |
| `-` | 延音（一個 `-` 佔一拍）。`5---` 同 `5 - - -`一樣 |
| `_` | 減時線（`5_` 八分、`5__` 十六分）。相鄰嘅音會自動駁埋一條線 |
| `.` | 附點（`5.`） |
| `^` / `v` | 高／低八度（`^1` `vv5`，最多三個） |
| `#` `b` `n` | 升／降／還原（`#4` `b7` `n3`） |
| `\|` `\|\|` | 小節線／終止線；`\|:` `:\|` 反覆記號 |

可以砌埋一齊：`^5._` = 高八度、附點、八分。

**連續音群唔使逐粒打 `_`** —— 用 `_( )` 包住成組：

```
_(3 5 5 3 5 3 5 3)      同  3_ 5_ 5_ 3_ 5_ 3_ 5_ 3_  一模一樣
__(3 4 3 2)             同  3__ 4__ 3__ 2__          一模一樣
```

括號入面照樣寫得其他記號：`_({C}3 5. ^1)`、小節線同 `-` 唔會被加減時線。
抄印刷譜嗰陣，一睇見一條長減時線罩住幾粒音，就直接 `_( )` 包晒佢。

### 由印刷簡譜抄過嚟：符號對照

一般簡譜集嘅印法 → 呢度嘅打法：

| 書上面印乜 | 打乜 | 例 |
|---|---|---|
| 數字下面**一條**橫線 | `_` | `5_` |
| 數字下面**兩條**橫線 | `__` | `5__` |
| 數字下面一條橫線＋右邊一點 | `._` 或 `_.` | `5._` |
| 數字**右邊**一點（附點） | `.` | `5.` |
| 數字**下面**一點（低八度） | `v` 前置 | `v5` |
| 數字**上面**一點（高八度） | `^` 前置 | `^1` |
| 上／下兩點（差兩個八度） | `^^` `vv` | `vv5` |
| `—` 橫杠（延音） | `-`，一杠一拍 | `5 - - -` |
| `0` | `0` | |
| `‖:` … `:‖` | `\|:` … `:\|` | |
| 段落用括號 `( )` 包住（樂器段） | 用段落標記 `[前奏]` 表示 | |
| 中途標「轉 1=A」 | 改「調：」，或者由嗰句起另開一個檔 | |
| 音符上面嘅和弦（C、Am7…） | `{C}` `{Am7}` 擺喺音符前 | `{Am7}6 7` |
| `1.` `2.` 反覆括號 | 音符行前面加 `%1.` `%2.` | |

**兩段歌詞上下疊住排**（好多譜集都係咁印）：音符只寫一次，
歌詞連續寫兩行就得，會自動疊住，同書一樣。

> **未支援**：圓滑線／連音線（音符上面嗰啲弧線）同波音記號，暫時畫唔到。
> 唔影響對位 —— 邊粒音係拖腔，睇歌詞留白就知（用 `-` 或者 `~`）。
> 如果你真係要嗰啲弧線，話我知，可以加。

### 和弦記號

用大括號擺喺音符前面，`{C}5` 或者 `{C} 5`都得：

```
{C}3 5 5_ 3_ | {Em}6 5 3 - | {Am7}6 7 {F7}3 5 | {Dm7}2 - - -
```

和弦會靠左印喺音符上面。**佢唔會撐闊欄位** —— 就算打 `{F#m7b5}` 咁長，
排版一樣係跟歌詞，同冇和弦時一模一樣闊。冇和弦嘅句子唔會白白多咗一行位。

### 反覆括號（1. 2. 結尾）

音符行最前面加 `%1.` / `%2.`：

```
%1. {C7}3 - 3_ 4_ | {Dm7}2 - - 0
第一次結尾

%2. {C7}3 - 3_ 4_ | {Dm7}2 - - -
第二次結尾
```

括號只會罩住嗰句嘅實際長度，唔會拉到成行咁闊。

### 歌詞寫法

- **中文冇空格**：逐個字自動分配（`一閃一閃亮晶晶`）。標點會黐返上一個字。
- **有空格**：照空格分（英文歌詞、或者想手動控制邊個字對邊粒音）。
- 一個字配一粒音。**休止符（`0`）同延音（`-`）唔會食字。**
- `-` = 呢粒音唔要字（留空）；`~` = 拖腔線（畫一條橫線）。

打譜嗰陣如果歌詞多過音符，螢幕會出黃色提示話你知尾幾個字擺唔落
（呢個提示唔會印出嚟）。

## 抄譜校對（慳最多時間嗰部分）

抄譜最花時間唔係打字，係校對。呢度自動幫你捉兩種錯，
兩種提示都**只喺螢幕出現，唔會印出嚟**：

| 顏色 | 捉乜 |
|---|---|
| 🟡 黃色 | 歌詞同音符數量對唔上 —— 話你知尾幾個字擺唔落 |
| 🔵 藍色 | **小節拍數唔啱** —— 「第 12 小節係 3.5 拍，爭 0.5 拍」 |

拍數檢查會自動由「拍：」讀拍號（`4/4`→4 拍、`3/4`→3 拍、`6/8`→3 拍）。
漏咗一條減時線、少咗個附點、多打咗個 `-`，即刻現形，唔使你逐粒對返原譜。

細節：
- 小節可以跨句 —— 拍數會一路累加落去，唔會因為斷行就算錯
- 句尾啱啱夠拍就當收咗一節（好多譜靠斷行代替最後嗰條小節線）
- 第一個小節短拍當**弱起**，唔會報
- **「拍：」留空就唔查** —— 散板、自由拍嘅譜啱用

## 可調嘅嘢

譜字大細、歌詞大細、音符間距、**留白高度**、行距、頁邊、
留白橫線（無／虛線／點線／實線）、
紙張（A4 直／A4 橫／Letter）、英文註解印唔印。

**行寬**兩個選擇：

- `跟歌詞長度（靠左）` — 完全唔撐開，一句幾長就幾長（預設）
- `每句撐開` — 撐開得舒服啲，但**短句唔會攤到成行咁散**：
  一句最多只撐到自己自然闊度嘅 1.5 倍。夠長嗰啲先至真係填滿一行。

設定同原稿都會自動記喺瀏覽器度，下次開返一樣。

## 檔案

| 檔案 | 做乜 |
|---|---|
| `index.html` | 介面、控制項、列印 |
| `jianpu.js` | 原稿解析 + 排版 + 一句塞一行嘅計算 |
| `leadsheet.css` | 紙面樣式、簡譜符號、列印版面 |
| `songs.js` | 兩個內建示範 |
| `songs/*.txt` | 起好咗骨架嘅歌（標題／詞曲 credit／段落），等你填音符同歌詞 |

`songs/` 入面嘅檔案用「開啟 .txt」載入，填完用「下載 .txt」存返。

> ⚠️ 呢個工具只係排版。受版權保護嘅旋律同歌詞，請由你自己合法擁有嘅譜
> （買嘅樂譜、授權版本）或者自己聽寫填入，唔好抄網上未授權嘅來源。

## 印刷

「列印 / 存 PDF」會用 `@page` 嘅邊界，所以第二頁開始一樣有上下邊界。
螢幕預覽嘅內文闊度同印出嚟完全一樣，所以喺螢幕見到點樣壓縮，印出嚟就係咁。
一句（連同佢下面嘅留白）唔會被分頁斷開。

在瀏覽器嘅列印對話框入面，記得**「背景圖形」開咗**（如果想印留白嘅橫線），
同埋**邊界揀「預設」**（唔好揀「無」，唔係就會用返瀏覽器嘅設定）。
