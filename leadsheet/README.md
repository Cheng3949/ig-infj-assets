# 簡譜排版器 — 一句一行

專門排「一句歌詞 = 一行」嘅簡譜（lead sheet），同一般填滿式嘅譜唔同。

**點用**：直接用瀏覽器開 `leadsheet/index.html`（唔使裝嘢、唔使開 server），
左邊打字、右邊即時見到排版，撳「列印 / 存 PDF」就印得。

## 三個設計重點

| | 做法 |
|---|---|
| **一句一行** | 每句歌詞永遠唔會被斷開。斷行位由你喺原稿入面決定，唔係由紙嘅闊度決定。 |
| **每行下面留白** | 每句下面固定留一段白，用嚟手寫筆記，或者打一行英文歌詞（`>` 開頭嗰行）。高度可調。 |
| **闊度跟歌詞** | 每粒音符嘅欄闊 = 個字有幾闊（中文字通常闊過數字），唔係跟音符。 |

句子太長塞唔落一行嘅時候，會**自動**：先收窄音符之間嘅間距 → 仲唔夠就橫向壓窄字體 →
再唔夠就連字級一齊縮細。總之一定塞返晒喺同一行。

## 原稿格式

```
標題：小星星
調：1=C
拍：4/4
曲：法國民謠

[A]
1 1 5 5 | 6 6 5 -
一閃一閃亮晶晶
> Twinkle, twinkle, little star,

4 4 3 3 | 2 2 1 - ||
滿天都是小星星
> How I wonder what you are.
```

一句 = 一組行，**用空行分隔**：

1. **第一行**：音符
2. **第二行**：歌詞（想要第二段歌詞就再寫多一行，會疊喺下面）
3. **`>` 開頭**：印喺留白入面嘅字（英文歌詞、和弦、提示……可以有幾行）

### 標題資料（放喺最頂）

`標題` `副標題` `調` `拍` `速度` `詞` `曲` `編曲` `唱` `備註`
（英文 `title` `key` `time` `tempo` `lyricist` `composer` 等都得）

### 段落標記

用中括號自己一行：`[A]`　`[主歌]`　`[副歌]`　`[Bridge]`

### 音符寫法

| 寫法 | 意思 |
|---|---|
| `1`–`7` | 音；`0` = 休止符 |
| `-` | 延音（一個 `-` 佔一拍）。`5---` 同 `5 - - -`一樣 |
| `_` | 減時線（`5_` 八分、`5__` 十六分）。相鄰嘅音會自動駁埋一條線 |
| `.` | 附點（`5.`） |
| `^` / `v` | 高／低八度（`^1` `vv5`，最多三個） |
| `#` `b` `n` | 升／降／還原（`#4` `b7` `n3`） |
| `\|` `\|\|` | 小節線／終止線；`\|:` `:\|` 反覆記號 |

可以砌埋一齊：`^5._` = 高八度、附點、八分。

### 歌詞寫法

- **中文冇空格**：逐個字自動分配（`一閃一閃亮晶晶`）。標點會黐返上一個字。
- **有空格**：照空格分（英文歌詞、或者想手動控制邊個字對邊粒音）。
- 一個字配一粒音。**休止符（`0`）同延音（`-`）唔會食字。**
- `-` = 呢粒音唔要字（留空）；`~` = 拖腔線（畫一條橫線）。

打譜嗰陣如果歌詞多過音符，螢幕會出黃色提示話你知尾幾個字擺唔落
（呢個提示唔會印出嚟）。

## 可調嘅嘢

譜字大細、歌詞大細、音符間距、**留白高度**、行距、頁邊、
留白橫線（無／虛線／點線／實線）、行寬（跟歌詞長度 ／ 每句撐滿一行）、
紙張（A4 直／A4 橫／Letter）、英文註解印唔印。

設定同原稿都會自動記喺瀏覽器度，下次開返一樣。

## 印刷

「列印 / 存 PDF」會用 `@page` 嘅邊界，所以第二頁開始一樣有上下邊界。
螢幕預覽嘅內文闊度同印出嚟完全一樣，所以喺螢幕見到點樣壓縮，印出嚟就係咁。
一句（連同佢下面嘅留白）唔會被分頁斷開。

在瀏覽器嘅列印對話框入面，記得**「背景圖形」開咗**（如果想印留白嘅橫線），
同埋**邊界揀「預設」**（唔好揀「無」，唔係就會用返瀏覽器嘅設定）。
